# Öztürk Doğrama Website

A static, minimalist website for Öztürk Doğrama — a carpentry business specializing in custom wooden doors and fitted cupboards.

## Pages
- `index.html` — Home
- `products.html` — Products (doors & cupboards)
- `about.html` — About the company
- `contact.html` — Contact form & info

## Files
- `style.css` — shared styles
- `script.js` — mobile nav + contact form handling

## Deploying for free
This is a static site, so it can be hosted for free on **GitHub Pages**:

1. Push this repo to GitHub.
2. Go to the repo's **Settings → Pages**.
3. Under "Source," select the `main` branch and `/ (root)` folder.
4. Save — your site will be live at `https://ecetuanahezer.github.io/ozturkdogramawebsite/` within a minute or two.

## To customize
Swap the gradient placeholder blocks (`.ph-image`) in `products.html` and `index.html` for real photos, and update the phone, email, and address placeholders in `contact.html` and the footer.
